# Reuse disclosure

The files baseline/engine.py and baseline/models.py are copied unchanged from
the existing ByggeKlar Agent app folder on 7 September 2026. Their original MIT
license is preserved in LICENSE. They are pre-existing work and must not be
presented as new Amazon hackathon work.

New work: server.py, validation at the tool boundary, MCP stdio session handling,
and test_server.py. No Alexa or Amazon runtime connection has been demonstrated.
No prior submitted artifact is modified by this standalone package.

Subsequent new integration work includes the official-SDK Streamable HTTP entry
point, local browser demonstrator, structured-result export, HTTP-chain checks,
and interface styling and documentation revised on 16 September 2026. These
additions reuse the same baseline engine; they do not make its original logic new.
The browser interface is a local client, not proof of an Alexa integration.
